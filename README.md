# مفتاح البرمجة

تطبيق تعليمي عربي يعمل في المتصفح لتعلم أساسيات **C++** و**HTML** و**SQL** باستخدام كلمات عربية. يترجم التطبيق الكلمات العربية إلى كود قياسي، يعرض الكود المترجم، ثم يشغّل النتيجة داخل المتصفح دون إرسال الكود إلى خادم.

## التشغيل السريع

المتطلب الوحيد هو Node.js 20 أو أحدث. لا توجد حزم npm مطلوبة.

```powershell
cd C:\Users\kapor\arabic-code-lab
npm start
```

ثم افتح:

```text
http://localhost:4173
```

لإيقاف الخادم اضغط `Ctrl + C`.

## الاختبارات

```powershell
npm test
```

تغطي الاختبارات تحويل الكلمات العربية، ترجمة C++ وHTML وSQL، الحفاظ على النصوص والتعليقات، الأرقام والفواصل العربية، معالجة الأخطاء، وصلاحية جميع الأمثلة المدمجة.

## المزايا

- محرر عربي مع أرقام أسطر، اختصارات `Ctrl + Enter`، وأمثلة جاهزة لكل لغة.
- عرض الكود المترجم مع زر نسخ.
- تشغيل C++ داخل Web Worker باستخدام JSCPP.
- تنفيذ SQL على قاعدة بيانات SQLite داخل المتصفح باستخدام sql.js.
- معاينة HTML داخل إطار معزول مع تعطيل JavaScript.
- واجهة عربية من اليمين إلى اليسار، مع الحفاظ على اتجاه الكود نفسه.
- رسائل خطأ عربية، وإعادة ضبط قاعدة البيانات، وعرض الجداول الحالية.
- تشغيل محلي بالكامل، دون خادم تنفيذ أو خدمات خارجية.

## أمثلة

### C++

```cpp
صحيح رئيسية() {
    صحيح العمر = 20;
    إذا (العمر >= 18) {
        اطبع "بالغ" << سطر_جديد;
    } وإلا {
        اطبع "قاصر" << سطر_جديد;
    }
    أرجع 0;
}
```

### HTML

```html
<صفحة>
  <جسم>
    <عنوان_رئيسي>مرحبًا بكم</عنوان_رئيسي>
    <فقرة>صفحة مكتوبة بوسوم عربية.</فقرة>
  </جسم>
</صفحة>
```

### SQL

```sql
اختر الاسم، العمر، المدينة
من الطلاب
حيث العمر >= 20
ترتيب حسب العمر تنازليًا؛
```

## كيف يعمل التحويل؟

1. يطبّع المحوّل النص العربي: الهمزات، التشكيل، الأرقام العربية، والفواصل العربية.
2. يحلل الكود مع تجاهل النصوص والتعليقات حتى لا تُترجم كلماتها.
3. يستبدل الكلمات العربية بما يقابلها في اللغة الهدف.
4. يحوّل أسماء المتغيرات العربية إلى أسماء ASCII متسقة.
5. يعيد الناتج للعرض أو للتنفيذ، مع مواضع أخطاء مرتبطة بالكود الأصلي.

## المشغّلات والقيود

- **C++**: يستخدم JSCPP داخل المتصفح. يدعم المتغيرات الرقمية والمنطقية، الشروط، الحلقات، الدوال، والمدخلات. لا يدعم `std::string` أو مكتبات C++ الكاملة؛ متغيرات النص تحتاج مشغّلًا أصليًا مثل `g++`. يمكن نسخ الكود المترجم وتشغيله خارجيًا.
- **SQL**: قاعدة بيانات SQLite في الذاكرة، تبدأ بجدولي `الطلاب` و`المواد`. التغييرات تبقى حتى إعادة الضبط أو إعادة تحميل الصفحة.
- **HTML**: المعاينة داخل `iframe` معزول مع تعطيل JavaScript.
- **الخصوصية**: لا يُرسل الكود إلى أي خادم؛ الخادم المحلي يقدم الملفات الثابتة فقط.
